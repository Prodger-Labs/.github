# Prodger Labs

Personal engineering org for Sam Prodger: Gravitee AI agent governance work, RNLI Poole Lifeboat Station operational tooling, and home automation, in one place.

## What's Here
- Gravitee migration tooling, policy plugins and demo stacks for agent identity, MCP and LLM governance.
- Operational tooling for Poole Lifeboat Station: crew availability, AIS tracking, wall dashboards, exercise planning.
- Home Assistant config and automations for a Home Assistant Green running three years.
- Infrastructure for The Interconnect, including an MCP server exposing it to agents.

## Public
Most of this is private working repos, not built for an audience. The one that is:
- [interconnect-mcp](https://github.com/Prodger-Labs/interconnect-mcp) — MCP server for The Interconnect, so agents can read and cite the blog directly.
